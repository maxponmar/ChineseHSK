## Download the HSK1 deck

The deck contains **1,352 cards** with Mandarin audio, visual icons, and Spanish and English translations.

1. Click the following link: **[Download HSK1 Anki Deck](https://github.com/maxponmar/ChineseHSK/releases/latest)**
2. On the page that opens, find the **"Assets"** section
3. Click the file ending in **`.apkg`** (for example, `HSK1_Complete.apkg`)
4. The file will automatically download to your downloads folder

:::tip[The file is safe]
The `.apkg` file is an Anki format. It is completely safe and only contains study cards, audio, and images.
:::

## What does the deck contain?

| Category | Quantity | Description |
|----------|----------|-------------|
| HSK1 Vocabulary | 140 words | All words from the HSK1 course |
| Everyday phrases | 70 phrases | Greetings, food, shopping, social life |
| Work phrases | 80 phrases | Meetings, technology, emails, calls |
| Grammar | 48 structures | Grammar patterns from the textbook |
