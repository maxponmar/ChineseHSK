## Import the deck

### Option 1: Double-click (easiest)

1. Find the **`HSK1_Complete.apkg`** file in your downloads folder
2. **Double-click** the file
3. Anki will open automatically and ask if you want to import
4. Click **"Import"**
5. Done! The "Chinese HSK1" deck will appear in your deck list

### Option 2: From inside Anki

1. Open **Anki**
2. Go to the **File** menu → **Import**
3. Find and select the **`HSK1_Complete.apkg`** file
4. Click **"Import"**

:::tip[Already have an older version?]
If you've imported this deck before, don't worry. Anki will **update** the cards automatically and **preserve your study progress**. You won't lose anything.
:::

## What will you see after importing?

After importing, you'll see a new deck called **"Chinese HSK1"** on Anki's main screen. The number next to the deck shows how many new cards you have to study today.
